# Repository Summary: TailAdmin Next.js Dashboard

## What This Repository Does

This repository contains **TailAdmin**, a free and open-source admin dashboard template built with **Next.js 15** and **Tailwind CSS**. It provides a complete solution for building feature-rich, data-driven admin dashboards and control panels.

## Key Purpose

TailAdmin serves as a pre-designed starting point for developers who need to create:
- Admin dashboards
- Control panels
- Data visualization interfaces
- Back-end management systems
- Web application admin interfaces

## Technology Stack

- **Next.js 15.x** - React framework with SSR/SSG capabilities
- **React 19** - Latest React version
- **TypeScript** - Type-safe JavaScript
- **Tailwind CSS V4** - Utility-first CSS framework
- **ApexCharts** - Data visualization library
- **Various UI Libraries** - For enhanced components

## Core Features

### Dashboard Components
- **1 Unique Dashboard** (30+ components in free version)
- **50+ UI Elements** including:
  - Sophisticated sidebar with collapsible functionality
  - Data visualization components (charts, tables)
  - Profile management pages
  - Custom 404 pages
  - Authentication forms and input elements
  - Alerts, dropdowns, modals, buttons
  - Dark mode support

### Advanced Features
- **Calendar Integration** - Using FullCalendar
- **Vector Maps** - Geographic data visualization
- **Drag & Drop** - Interactive UI elements
- **File Upload** - Dropzone functionality
- **Date Pickers** - Flatpickr integration
- **Interactive Charts** - Line and bar charts
- **Responsive Design** - Mobile-first approach

## Project Structure

```
src/
├── app/          # Next.js App Router structure
├── components/   # Reusable UI components
├── context/      # React context providers
├── hooks/        # Custom React hooks
├── icons/        # SVG icons
├── layout/       # Layout components
└── svg.d.ts      # TypeScript definitions
```

## Getting Started

1. **Clone the repository**
2. **Install dependencies**: `npm install`
3. **Start development server**: `npm run dev`
4. **Build for production**: `npm run build`
